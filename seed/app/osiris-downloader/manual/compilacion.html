Compilación

Requisitos

ComponentePara qué
GCC o Clang (GNU C11)Usa goto * (computed goto) y __attribute__((cleanup)). MSVC no sirve.
SDL2 ≥ 2.0.14 y SDL2_ttf (desarrollo)Ventana, renderizado y texto.
pkg-config, make (o CMake ≥ 3.10)Localizar librerías y compilar.
Una fuente TTFDejaVu, Liberation, Noto, Ubuntu o Arial; se busca sola.
yt-dlp (en ejecución) y ffmpegDescargar y convertir/mezclar.

Instalación de dependencias

Automática

./install-deps.sh

Manual

# Debian / Ubuntu / Mint
sudo apt install build-essential pkg-config cmake libsdl2-dev libsdl2-ttf-dev fonts-dejavu-core ffmpeg xdg-utils
# Fedora
sudo dnf install gcc make pkgconf-pkg-config cmake SDL2-devel SDL2_ttf-devel dejavu-sans-fonts ffmpeg-free
# Arch / Manjaro
sudo pacman -S base-devel cmake sdl2 sdl2_ttf ttf-dejavu ffmpeg
# macOS (Homebrew)
brew install pkg-config cmake sdl2 sdl2_ttf ffmpeg yt-dlp

yt-dlp

mkdir -p ~/.local/bin
curl -L https://github.com/yt-dlp/yt-dlp/releases/latest/download/yt-dlp -o ~/.local/bin/yt-dlp
chmod +x ~/.local/bin/yt-dlp
yt-dlp -U        # actualizar cuando un sitio deje de funcionar

Compilar

Opción 1: script

./build.sh

Opción 2: make

make            # release (-O2)
make debug      # con AddressSanitizer y UBSan
make clean

Opción 3: CMake

cmake -S . -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build
./build/bin/osiris-downloader

Con make el binario queda en build/osiris-downloader; con CMake en build/bin/.

Ejecutar

./build/osiris-downloader
OSIRIS_FONT=/ruta/a/fuente.ttf ./build/osiris-downloader   # forzar una fuente

Instalar en el sistema (opcional)

sudo install -m755 build/osiris-downloader /usr/local/bin/

Windows

El código usa APIs POSIX (posix_spawn, kill sobre grupo de procesos, pthread).

  • WSL2 (recomendado): Windows 11 incluye WSLg, así que las ventanas SDL aparecen directamente. Dentro de Ubuntu sigue los pasos de Linux.
  • MSYS2 / MinGW: no soportado de serie; habría que sustituir el lanzador de procesos de core.c por CreateProcess y las señales por TerminateProcess.

Usar SDL3 en el futuro

La interfaz usa solo ventana, renderer, eventos de ratón/teclado/texto y TTF. Migrar a SDL3 implica cambiar SDL_RenderSetClipRect → SDL_SetRenderClipRect, la API de eventos de ratón, SDL_CreateWindow, y usar SDL3_ttf. Todo el cambio se concentra en ui.c y main.c.
