Solución de problemas

Compilación

Package 'sdl2' not found / SDL2_ttf not found

Faltan los paquetes de desarrollo: instala libsdl2-dev libsdl2-ttf-dev (Debian/Ubuntu) o ejecuta ./install-deps.sh. Comprueba con:

pkg-config --modversion sdl2 SDL2_ttf

fatal error: SDL.h: No such file

Compila con make o CMake (usan pkg-config, que añade -I/usr/include/SDL2). No uses #include <SDL2/SDL.h> a mano.

Error en goto * o cleanup

Usas un compilador sin extensiones GNU (MSVC). Usa GCC o Clang con -std=gnu11.

SDL instalada en una ruta no estándar

PKG_CONFIG_PATH=/opt/sdl2/lib/pkgconfig make

Ejecución

«No se encontró ninguna fuente TTF»

Instala fonts-dejavu-core o apunta a una fuente: OSIRIS_FONT=/ruta/fuente.ttf ./build/osiris-downloader, o copia una fuente a ./font.ttf en el directorio desde el que ejecutas.

«yt-dlp NO encontrado»

Instálalo (ver Compilación) o escribe su ruta completa en Opciones. Comprueba que es ejecutable: ls -l $(which yt-dlp).

Aparece «No se pudo ejecutar yt-dlp»

La ruta configurada no existe o no tiene permiso de ejecución. Mira el registro: el mensaje incluye la razón del sistema.

El audio no se convierte / no hay miniatura

Falta ffmpeg (o AtomicParsley para algunos formatos). Instálalo con tu gestor de paquetes.

Error 403, «Sign in to confirm you’re not a bot» o vídeo no disponible

Actualiza yt-dlp (yt-dlp -U). Si el sitio exige sesión, elige tu navegador en «Cookies del navegador». Revisa el registro para ver el mensaje exacto.

La ventana no abre (Wayland / SSH / WSL)

Prueba SDL_VIDEODRIVER=x11 ./build/osiris-downloader o SDL_VIDEODRIVER=wayland. Por SSH necesitas ssh -X. En WSL2 necesitas Windows 11 / WSLg.

Interfaz con poca nitidez en pantallas HiDPI

Está pensado para escala 1×. Si se ve pequeña, usa la escala del escritorio o cambia el tamaño de fuente (15) en main.c (ui_init(&a->ui, ren, 15)).

El texto con acentos no se escribe

Los campos usan eventos de texto de SDL (UTF-8). Comprueba que tu entorno proporciona un método de entrada; las teclas muertas deberían funcionar con IBus/Fcitx.

Depuración

make clean && make debug      # AddressSanitizer + UBSan
./build/osiris-downloader
# Probar sin descargar nada, con un yt-dlp falso:
printf '#!/bin/bash\necho "[download]  50.0%% of 10MiB at 1MiB/s ETA 00:05"; sleep 3\n' > /tmp/fake && chmod +x /tmp/fake
# Opciones → Ruta de yt-dlp: /tmp/fake

Para reiniciar la configuración borra ~/.config/osiris-downloader/settings.ini.
